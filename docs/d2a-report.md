## 六、诚实记录的三个问题

### 6.1 冻结 query 集混有「验证规格」而非自然问句

12 条中约 5 条（`R0NEW-AMT-01/ALIAS-01/NEG-01/DATE-01/VENDOR-01`）原文是验证说明，例如 `确认库中确实不存在匹配结果才设置 expected_empty=true（当前为 null）`。
拿它们**原样**投入按「产品＋金额」措辞的演示入口，测不到 D2a 的意图。本报告因此**另辟一列**同维度自然语言问法作为补充——**两者都报，未替换预注册选题**。

### 6.2 Demo 合同范围远小于冻结问题预期

`G01 找50万以上的代谢组合同` 冻结 `expected_count=29`，**Demo 返回 0 条**——因为演示库只覆盖 **2 份已核合同**（19.98 万单细胞 / 9.76 万多组学）。
这是**范围限制，不是缺陷**；但意味着冻结 query 的 `expected_count` 在 Demo 阶段不可用。

### 6.3 方案主题检索未实现

`售后/培训/质量控制` 三个方案维度均被明确拒绝。方案入口只有一份冻结的**售后服务**示范稿；培训与质控无预览。按用户裁定：**未支持的冻结问题不要求本轮实现，诚实拒绝并进入后续清单**。
