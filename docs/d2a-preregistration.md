## 判定口径

| 状态 | 含义 |
|---|---|
| 成功 | 支持范围内，返回结果正确（路径真实、证据或缺口明确） |
| 正确无结果 | 支持范围内，确实无匹配且如实返回空 |
| 明确不支持 | 条件超出当前能力，系统**明确拒绝**而非静默忽略 |
| 错误命中 | 返回了不该返回的结果 |
| 错误漏检 | 应返回却未返回 |
